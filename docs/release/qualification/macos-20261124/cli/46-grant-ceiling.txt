# 46-grant-ceiling: the grant limits (128 in all, 16 per pane) and the delegation ceiling (grant_exceeds_holder), over raw JSON-RPC
# docs (scripting.md): 'Paneflow holds at most 128 grants, 16 per pane. Past that, grant.request and grant.delegate answer
#   {granted: false, reason: grant_limit} and no prompt is shown.' 'the rights and the scope must be within a grant it holds, and the expiry
#   no later than that grant's (grant_exceeds_holder otherwise)... A pane it did not spawn is refused with not_spawned_by_caller.
#   Revoking a grant revokes everything delegated from it.'
# setup: paneflow.json agents.claude.grants lists the 16 distinct (rights, scope) pairs (8 rights sets incl. [], x workspace|instance),
#   ipc gates closed. Nine panes run a binary named claude (a compiled sleep loop, fakebin/claude) in the foreground, so Paneflow
#   grants each the profile: panes 5152-5159 (workspace 'grants') and 1026 (workspace 'rpcq'). Each runs proxy.py in the background,
#   which sends the JSON-RPC calls from inside the pane. A prompt.follow subscriber (external, worker) logs every prompt frame.
