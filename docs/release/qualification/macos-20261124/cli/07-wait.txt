$ paneflow wait --help
Block until a pane goes idle, or a regex appears in its output (orchestration)

Usage: paneflow wait [OPTIONS] --match <SELECTOR>

Options:
      --match <SELECTOR>   Target: surface id, name, `cmdline:<substr>`, or `cwd:<path>`. Note: `cmdline:` matches the full argv on Linux but only the executable basename on macOS/Windows; prefer `cwd:` or a name for a portable selector
      --pattern <PATTERN>  Regex to wait for in the pane's recent scrollback. Required unless `--idle` is set. With `--idle` it is an optional sentinel: it is checked on each new output and EITHER signal (pattern match OR going idle) returns first (EP-003 US-008)
      --idle               Wait until the pane's agent ends its turn: for an agent that declares its state through OSC 7501, return on its next idle or attention state (at once if it already waits). Other panes wait for their output to go quiet (no `output_generation` change for `--for` ms) on the push stream. Single-target
      --for <MS>           With `--idle`: the quiescence window in milliseconds (default 1000). The pane must produce no new output for this long to count as idle
      --timeout <TIMEOUT>  Max seconds to wait before giving up (default 300)
      --any                Succeed as soon as ANY matching pane matches (selector may hit several). `--pattern` mode only; ignored with `--idle`
      --all                Require ALL matching panes to match the pattern. `--pattern` mode only
  -h, --help               Print help
[exit=0]
