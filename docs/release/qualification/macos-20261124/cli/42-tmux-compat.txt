# 42-tmux-compat: tmux.compat (the Claude Code agent-team tmux shim) over the shim and over raw JSON-RPC
# docs: reference.md 'tmux.compat | team, surface_id, argv, scope_session? | tmux command from a Claude Code team pane; team is the token
#   Paneflow gave that team's panes, and the reply is {stdout, stderr, exit}'. features.md: the Claude Code (team) launcher entry (Linux, macOS);
#   'A team can only open, list, rename, and close its own panes. Typing into a teammate with send-keys follows the same ipc.scripting
#   rule as paneflow send.' There is no paneflow.json key for tmux.compat; the shim is $PANEFLOW_HOME/bin/tmux-compat/tmux -> paneflow.
# setup: config ipc.scripting=false, ipc.orchestration=false, no agent grants. A stand-in 'claude' script was placed in
#   $PANEFLOW_HOME/bin/tmux-compat/ (first on the team launcher's PATH) so the real Claude Code never ran; it logs every tmux call
#   it makes and then execs a sleep loop. The Claude Code (team) entry was picked in the dev window's New pane palette (the only way
#   Paneflow issues a team token: src-app/src/app/pane_palette.rs). Lead pane: surface 10314. The token is redacted below.
