Build: worktree branch on main 347305f9 + fix(notifications) 2752968c (code identical to the builds tested); macOS 27.2 Apple Silicon; $SCRATCH = the session scratchpad.
Config of both runs: "agent_panel": {"notify_when_agent_waiting": "PrimaryScreen"}, "ipc": {"scripting": true}, spaces Work (blue) and Play (green).
Repro: a Work workspace and a Play workspace, Play shown, then the hidden Work pane runs
