## 3. Accessibility: language server banner, Cmd+click file finder
Opened src/main.rs: the consent banner "Start rust-analyzer for $L/repo? A language server can run this
project's build scripts." (134-small-ui-ls-banner.png). AX:
    button 'Start'    [Click, SetFocus]
    button 'Not now'  [Click, SetFocus]
Headless press on 'Not now' -> the banner left the AX tree and the screen; the dev build started no
rust-analyzer (the only rust-analyzer process running predates the instance and belongs to another tool).
File finder: client.dispatch_action open_file_finder, set-value "q/helpers.rs" in 'Search files' (the query a
Cmd+click on an ambiguous q/helpers.rs:3 fills in). AX:
    search 'Search files'
      textfield 'Search files' [focused]
      button 'Clear search files'
    list 'Files'
      option 'p/q/helpers.rs' [selected]   (agent-desktop prints the option role as statictext, with refs)
      option 'r/q/helpers.rs'
Headless press on 'r/q/helpers.rs' -> the dock opened helpers.rs (tab 'helpers.rs', 'Close helpers.rs').
The finder was already exposed (05576323); the observation came from C9, where the finder never opened.
