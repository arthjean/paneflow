How an agent launcher resolves its binary (code read, no execution):
- agent_launcher.rs launch_command renders the preset command (for example `claude ...`) and wraps it with clear_then, so the pane shell resolves it on the pane PATH.
- The pane PATH starts with $PANEFLOW_HOME/cache/bin/<version> (paneflow-shim copies named after each agent). The shim (crates/paneflow-shim/src/detect.rs find_real_binary_in) walks PATH in order and takes the first match that is not a shim or helper dir.
- The app rebuilds its own PATH at start: login_shell_env.rs adopts PATH from `$SHELL -l -i -c env` (path_helper puts system dirs first and appends the inherited entries), then runtime_paths.rs augment_path_for_gui_launch PREPENDS ~/.bun/bin, ~/.cargo/bin, ~/.local/bin, /opt/homebrew/bin and /usr/local/bin when they are not on PATH yet.
