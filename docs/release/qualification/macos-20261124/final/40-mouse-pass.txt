== notes
A. Controls a mouse reaches but the accessibility tree does not list in this build (agent-desktop snapshot, and a raw AX walk for the
   files rows): the welcome screen rows (Open folder…, Clone repository…, Open command palette, Agent profiles, Keyboard shortcuts,
   Appearance) and the sidebar's empty-state Open folder / Clone repository; the options of an open Settings dropdown; the command
   palette rows; the files sidebar rows; the Changes dock file rows; the dock's '+' button. Each one works with the mouse above.
B. 'agent-desktop --headed click <ref>' refuses every element of this app before any input ("Physical input target could not be
   proven at the final input point"): GPUI answers no AX hit test at a point. Physical clicks were therefore sent by coordinates.
C. The tab menu shows its Branch section (New branch…, the branch list) only when the repository has more than one checkout
   (src-app/src/app/sidebar/context_menu.rs, show_checkouts = checkouts.len() > 1, unchanged since 7dc9997b). worktrees.md says
   "The tab's context menu offers New branch… for a tab that already exists" without that condition. In final/22 (a330868a) the
   repo had a second branch, so the section showed. Repro: git init a repo with only main, paneflow new --cwd <repo>, right-click
   its tab (or Shift+F10): only Rename and Close tab.
