### C11: a simple command entry has no UI
Command palette (Cmd+Shift+P): 'qa-' -> 'No matching command'; 'qa' lists Equalize panes, Interface style, Show pull requests in the sidebar, Quit Paneflow. qa-run is nowhere: not in the palette, not in Settings > Workspaces (which lists only 'Open template qa-tpl'). In the source, config.commands is read only by settings/tabs/workspaces (templates). The schema says commands entries back 'Command palette entries and workspace templates'.
Custom command buttons are a different feature and work: workspace context menu > 'Manage custom buttons…' > New button (name 'QA Echo', command 'echo custom-button-ran') stores the button in session.json; it then appears at the end of the pane '+' chooser (the list scrolls), and choosing it opened pane 32911 that printed 'custom-button-ran'. The New button dialog is not exposed to accessibility.
