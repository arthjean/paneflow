== JSON-RPC idle close (reference.md Request model): connect, optionally send one request, then wait up to 90 s
reply: {"jsonrpc":"2.0","id":1,"error":{"code":-32010,"message":"host.hello must be the first request on a connection"}}
HOST_SOCK after-request: closed by server after 0.0 s idle
HOST_SOCK no-request: closed by server after 10.0 s idle
reply: {"jsonrpc":"2.0","result":{"pong":true},"id":1}
WIN_SOCK after-request: closed by server after 30.0 s idle
WIN_SOCK no-request: closed by server after 30.0 s idle
reply: {"jsonrpc":"2.0","id":1,"error":{"code":-32010,"message":"worker.hello must be the first request on a connection"}}
WORKER_SOCK after-request: closed by server after 0.0 s idle
WORKER_SOCK no-request: closed by server after 60.0 s idle
Window endpoint: closed after 30.0 s with and without a prior request, as documented. Host (10 s) and worker (60 s) are separate protocols that require host.hello / worker.hello first.
