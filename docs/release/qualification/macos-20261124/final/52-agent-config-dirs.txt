## agent_prompts (row 584)
agent_prompts="paneflow" in paneflow.json; a debug worker leaves the hooks untouched ('a debug build leaves the agent integrations untouched; paneflow integrations install <runtime> --force points them at it'), so: paneflow integrations install claude-code --force (HOME=fakehome) and the same with CLAUDE_CONFIG_DIR=$SCRATCH/cover3/claude-work -> PermissionRequest (matcher *) and PreToolUse (matcher AskUserQuestion) run 'paneflow-ai-hook.sh <event> answer' with timeout 600; the other events keep timeout 5.
From a Claude Code stand-in pane in space Work (PANEFLOW_AI_TOOL=claude, session and host endpoint set), $SCRATCH/cover3/perm.sh read the PermissionRequest command from $CLAUDE_CONFIG_DIR/settings.json and piped Claude Code's payload into it:
- {"hook_event_name":"PermissionRequest","tool_name":"Bash","tool_input":{"command":"rm -rf build"}} -> Paneflow prompt 'Bash / command: rm -rf build / Asked by Claude Code in Claude Code' with Allow once, Deny, Decide in the terminal (52-agent-prompts.jpg, top). Deny -> hook stdout {"hookSpecificOutput":{"decision":{"behavior":"deny","message":"The user denied this in Paneflow"},"hookEventName":"PermissionRequest"}}, exit 0, 12 s after the call.
- PreToolUse AskUserQuestion 'Which color?' (Red, Blue) -> prompt with Red, Blue, Answer in the terminal (bottom). Blue -> {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"allow","updatedInput":{"answers":{"Which color?":"Blue"},...}}}.
agent_prompts="native" plus a reinstall -> the hook has no 'answer' argument; the same PermissionRequest returns at once with no output and no prompt, so the question stays in the agent's terminal.
