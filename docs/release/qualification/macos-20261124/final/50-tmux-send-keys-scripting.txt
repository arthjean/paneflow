== verdict: send-keys -l types into a teammate once ipc.scripting=true (pass). FAIL: send-keys Enter (or C-m) is always refused, 'text contains CR or LF; multiline surface.send_text requires active bracketed paste': the shim maps Enter to CR and calls surface.send_text with paste=false and no submit, so a team can type into a teammate but never submit. paneflow send has --submit for this; send-keys has no equivalent path.
