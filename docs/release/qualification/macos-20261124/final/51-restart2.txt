## C16: PANEFLOW_WINDOW_BACKDROP has no effect on macOS
Repro: macos_chrome_material=true, no window_backdrop in paneflow.json; launch with PANEFLOW_WINDOW_BACKDROP=opaque (present in the app's environment, checked with ps -E). Result: Blended chrome (51-backdrop-env-opaque.jpg), while the same value in the config gives Themed. The schema says 'PANEFLOW_WINDOW_BACKDROP overrides it for one launch' without restricting it to Windows; in the code the variable is read only under cfg(windows) (src-app/src/app/constants.rs).
