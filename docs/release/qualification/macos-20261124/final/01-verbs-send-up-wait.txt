== note on 'wait --match agentB --pattern FAKE_AGENT_READY' (exit 4 above)
# agentB had printed FAKE_AGENT_READY before the wait started (search agentB READY finds it on line 2). wait --pattern
# matches only output that arrives after its baseline read (src-app/src/cli/wait_cmd.rs, read_baseline / text_after_baseline);
# the same wait on agentA matched because its line arrived after the wait began. Unchanged since 2176684e, so not a late
# regression; conductor/reference.md's "scans the latest 500 lines" reads as if existing output counted.
