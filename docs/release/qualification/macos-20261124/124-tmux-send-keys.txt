== teammate %2 (fake TUI agent with bracketed paste on): agent-bytes.log, one read() per line
b'\x1b[200~first prompt\x1b[201~'

# a prompt followed by Enter takes the paneflow send --submit path: bracketed paste, then a CR deferred until the echo, in a separate
# read, so the TUI cannot fold it into the paste. 'a Enter b Enter' in one call keeps its order (the second prompt waits for the first CR).
# Escape, Tab, BSpace and Up arrive as their keystrokes (ESC, HT, DEL, CSI A).

== verdict
PASS: send-keys Enter, C-m, 'x' Enter, 'echo Space hi Enter', C-c and the named keys reach the teammate in order once ipc.scripting=true;
with ipc.scripting=false both the text and the keystroke paths still refuse; -l stays literal; the leader still cannot be killed by the team.

== side finding (not fixed here)
The pane tab strip's "New tab" menu also lists 'Claude Code (team)', but launching it from there gives the lead no team token
(PANEFLOW_TMUX_TEAM empty), so every tmux call fails with "PANEFLOW_TMUX_TEAM is not set; this pane is not a Paneflow team pane".
Only the New pane palette (pane_palette.rs) issues the token; PaneEvent::NewTabPreset in app/event_handlers/mod.rs does not.
