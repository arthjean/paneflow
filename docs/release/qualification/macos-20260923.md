# macOS qualification report: persistent session path (2026-09-23)

Epic EP-006 of the persistent-session PRD, executed against the runbook in
[persistent-qualification.md](../persistent-qualification.md#macos-on-the-hosted-runner).
PRD v1.6 (2026-09-23) makes the hosted `macos-14` runner the required route:
the `MAC-ARM` cell is qualified on an Apple M1 virtual machine from a package
built and run by `.github/workflows/macos_qualification_package.yml`, and
renting a physical Mac is optional. Every verdict below is a shared-VM result.
Dedicated-hardware performance, an interactive smoke on a physical Mac,
local-display latency, macOS Intel, and the 480 min W08 run are recorded
`unavailable` or `optional`, never as passed.

The raw evidence this report cites is committed because workflow artifacts
expire after 30 days: the harness documents under `bench/results/`, and the
preflight ledger, screenshot, and host profiles under
[macos-20260923/](macos-20260923/).

The candidate returns to within 6 MiB of its empty footprint with every
thread and descriptor released; the baseline keeps 86 MiB and 60 threads.

output is 79.4 MiB for the candidate and 160.6 MiB for the baseline, and
after stopping all 8.0 MiB against 159.2 MiB. macOS resident size keeps
counting pages the kernel has not yet reclaimed (35.5 MiB after stopping all
against a 7.9 MiB footprint), so the footprint is the figure to compare.

CPU (`sample` of the host for 30 s): with 50 idle sessions the baseline host

viewport scan (`Pattern::is_contained_in`,

`PageFormatter.writeCellRun`, with 655 and 562 samples for the candidate
against 602 and 515 for the baseline.

attributed to the shared VM: each has a root cause in the code, the tests, or
the qualification tooling.

## Residual limits

- Every figure comes from a shared Apple M1 virtual machine with 3 vCPUs and
  7 GiB. Timings are recorded, not compared against dedicated hardware, and
  no performance claim for a physical Mac follows from them.
- macOS Intel (`MAC-X64`) is `unavailable`: no Intel runner or machine was
  exercised.
- The interactive smoke on a physical Mac, local-display input latency,
  peripherals, and production notarization are `unavailable`. The package is
  signed ad hoc by the linker; Gatekeeper reports it as unsigned (M09), which
  is expected for this route and says nothing about the notarized release.
- The desktop was exercised by the harness through its IPC (restoration of
  1, 10, and 50 panes, forced termination, and reopen), by the render smoke,
  and by the preflight screenshot; nobody drove it by hand.
- The desktop geometry calibration that forces 80x24 is implemented only on
  Windows, so the observed pane dimensions are recorded instead
  (`desktop_geometry: pending`).
- `sample` attributes wall-clock samples per thread, most of them blocked in
  the kernel; the CPU profiles show where on-CPU work goes, not a share of a
  core. The harness's per-thread CPU counters carry the CPU figures.
- The 480 min W08 run is `optional` and was not run; the 12 min rehearsal is
  the required W08 evidence.
