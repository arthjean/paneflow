### Inventory differences

`build-info.txt`: only the pin fields move (`source_sha`, `source_date_epoch`,
the four Zig URLs and digests, `headers_sha256`, `bindings_sha256`, the
canonical paths, `archive_sha256`, `symbol_count` 2,531 to 2,619,
`symbols_sha256`). The normalization recipe, `archive_members`, MSVC, SDK,
LLVM, `crt=MT_StaticRelease`, `cxx_runtime` and `system_libraries` are
unchanged.

`headers_index_sha256` (`6faf2082…` to `983fb016…`): the same 35 headers,
10 with new content (`formatter.h`, `kitty_graphics.h`, `osc.h`, `paste.h`,
`render.h`, `selection.h`, `size_report.h`, `snapshot.h`, `terminal.h`,
`types.h`), none added or removed. `vt.h` keeps `014813d7…`, the
`header_sha256` of the manifest.

`symbols_sha256` (`858437e2…` to `6453e5a7…`), on the `llvm-nm -j -g -U`
list: 557 removed and 645 added, in four groups.

| Group | Removed | Added | Cause |
|---|---|---|---|
| Public `ghostty_*` API | 1 | 7 | `ghostty_terminal_vt_write_until` replaces `ghostty_terminal_vt_write_until_ground`; the six additions are `ghostty_kitty_graphics_animation_tick` and `ghostty_render_state_image_{get,get_multi,iterator_new,iterator_next,iterator_free}`, as the PRD expects |
| compiler_rt exports | 23 | 23 | Zig 0.17.0: the 19 `f128` libm entry points are renamed from `*q` to `*f128` (`sinq` to `sinf128`, ...); `__divei5`, `__modei5`, `__udivei5` and `__umodei5` appear beside the existing `*ei4`; `__addo_limb64`, `__cmp_limb64`, `__subo_limb64` and `__memset` are gone |
| compiler_rt weak aliases `.weak.<fn>.default.<label>` | 462 | 462 | the 23 renames above, plus 439 aliases whose name only changes in the constant-pool label that ends it |
| Constant-pool labels `__xmm@`, `__ymm@`, `__real@` | 71 | 153 | literal constants emitted by the new code generator, named after their value |

`b68ed392b` (highway built without Zig stack protection under MSVC, part of
v1.4.0) leaves no symbol to diff: neither archive defines or references
`__security_cookie`, `__security_check_cookie` or `__GSHandlerCheck`, which is
the invariant that commit protects under Zig 0.17.0.

The dry run's Windows archive (`95fa652d…`, US-003) differs from the published
one (`c949db7d…`). This is expected: the Windows archive is built once and
attested, not reproducible (PRD Non-Goals).
