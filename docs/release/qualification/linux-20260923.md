## Operator checklist for the manual smoke

Run with the release desktop of the candidate on an isolated home and keep one
screenshot per check under `tasks/qualify-linux-ep005/captures/`. The desktop
IPC socket is not keyed by `PANEFLOW_HOME`, so `PANEFLOW_SOCKET_PATH` keeps the
test desktop away from a Paneflow already running on the machine.

```bash
cargo build --release --locked -p paneflow-app -p paneflow-host
export PANEFLOW_HOME="$(mktemp -d)"
export PANEFLOW_SOCKET_PATH="$PANEFLOW_HOME/ipc.sock"
printf '%s\n' '{"telemetry":{"enabled":false},"terminal":{"cursor_blink":"off"}}' > "$PANEFLOW_HOME/paneflow.json"
target/release/paneflow
```

Fixtures are typed in a pane's shell from `target/release/paneflow-session-fixture`.
A second terminal with the same two exports observes the state with
`target/release/paneflow host status` and `pgrep -af paneflow-session-fixture`.
Leave "Remember my choice" unchecked in the quit dialog.

| Check | Steps | Pass when |
|---|---|---|
| M-1 Keep running | Two panes running `paneflow-session-fixture idle`; note their session, generation, and pid in `host status`; Ctrl+Q, then Keep sessions running; relaunch `target/release/paneflow` with the same exports | Both panes show `fixture idle` again, and `host status` lists the same sessions with the same generation and pid |
