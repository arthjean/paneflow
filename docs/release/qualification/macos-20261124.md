# macOS qualification report: Apple Silicon hardware pass (2026-11-24)

Paneflow was already qualified on Linux and Windows. This pass checks, on a
physical Apple Silicon Mac, that everything `docs/user/` describes works in
the real app, closes the open macOS stories in `tasks/`, and fixes what it
finds. Every verdict below names its evidence. A check that cannot be run on
this machine is marked `unavailable` with the reason, never `pass`.

Evidence files named in this report live in
[macos-20261124/](macos-20261124/): every screenshot, downscaled to
1000 px JPEG, and every command transcript, with the CLI pass under `cli/`
and the worktree pass under `worktrees/`. The full-resolution set stays
local under `tasks/evidence/macos-qualification-20261124/`, untracked.
